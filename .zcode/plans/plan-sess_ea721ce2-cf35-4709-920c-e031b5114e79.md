## 小说阅读界面优化方案（两端同步）

### 共享层：ReadBookConfig 新增字段
两端的 `ReadBookConfig.kt` 同步添加：
```kotlin
val fontFamily: String = "serif",      // serif / sans-serif / monospace
val brightness: Float = 1.0f,          // 0.3~1.0，1.0=跟随系统
```
- KMP: `composeApp/src/commonMain/.../novel/ReadBookConfig.kt`
- Android: `E:\新建文件夹\java\...\book\entities\ReadBookConfig.kt`

---

### KMP 项目（RuleBasedCrawler）

**1. 键盘翻页 + 音量键** — `KmpNovelPagedView.kt`
- 添加 `FocusRequester` + `focusable()` + `onPreviewKeyEvent`
- 支持 ←/→/PageUp/PageDown/Home
- 添加 `VolumeKeyPageEffect`

**2. 设置面板扩展** — `ReaderScreen.kt`（ReaderSettingsPanel）
- 行距 Slider（5~30）
- 页边距 Slider（10~80）
- 字体选择 Row（宋体/黑体/等宽 FilterChip）
- 亮度 Slider（0.3~1.0）

**3. ViewModel + 持久化** — `ReaderViewModel.kt` + `SettingsRepository.kt`
- `ReaderSettings` 添加 `lineSpacing`、`margin`、`fontFamily`、`brightness`
- `AppSettings` 添加对应持久化字段
- 新增 Intent：`ChangeLineSpacing`、`ChangeMargin`、`ChangeFontFamily`、`ChangeBrightness`、`CopyCurrentPage`

**4. 字体应用** — `KmpNovelPagedView.kt`
- `TextStyle(fontFamily = when(config.fontFamily) { "sans-serif" -> FontFamily.SansSerif; "monospace" -> FontFamily.Monospace; else -> FontFamily.Serif })`

**5. 亮度控制** — `KmpNovelPagedView.kt`
- `brightness < 1.0` 时在 Canvas 上叠加 `drawRect(Color.Black.copy(alpha = 1 - brightness))`

**6. 复制当前页** — `ReaderScreen.kt` 底部菜单栏
- 小说模式显示"复制"按钮，取当前页文本写入剪贴板

---

### Android 项目（新建文件夹/java）

**7. 字体选择** — `ReadSettingsSheet.kt`
- 将"系统预设"TODO 替换为宋体/黑体/等宽 3 个选项
- 调用 `viewModel.updateConfig { it.copy(fontFamily = ...) }`

**8. 亮度控制** — `ReadView.kt`
- 读取 `config.brightness`，在 Canvas 上叠加半透明黑色 Box
- `ReadingSettingsScreen.kt` 的亮度 Slider 接入实际功能
